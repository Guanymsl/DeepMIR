# Music Generation

This project implements symbolic music generation using a GPT-2-based Transformer model with REMI tokenization.

- **Unconditional Generation (Task A):** Generate music from scratch without a musical prompt.
- **Conditional Generation (Task B):** Generate music continuations based on given MIDI prompts.

## Environment Setup

Create and activate a Python 3.11 virtual environment:

```bash
python3.11 -m venv venv
source venv/bin/activate
```

Install the required packages:

```bash
pip3 install -r requirements.txt
```

## Dataset Preparation

### POP909 Dataset

Place the **POP909** dataset under the `data/` directory with the following structure:

```text
data/
└── POP909/
    ├── training/
    └── prompts/
        ├── basic-b/
        └── bonus/
```

### MusDr Dataset

Place the **MusDr** dataset in the project root directory:

```text
MusDr/
└── ...
```

### SoundFont

Place **FluidR3_GM.sf2** in the `soundfonts/` directory:

```text
soundfonts/
└── FluidR3_GM.sf2
```

## Tokenization

Run the tokenization script with:

```bash
python3 tokenization.py
```

## Training

Run the training script with:

```bash
python3 train.py
```

## Prediction

Generate MIDI files using the trained model:

```bash
python3 predict.py [OPTIONS]
```

### Arguments

- `--task A/B`  
  Select the generation task:
  - `A`: unconditional music generation
  - `B`: conditional music generation from MIDI prompts

Generated MIDI files are saved under `outputs/generated/`.

## Evaluation

Evaluate the generated music using the provided evaluation metrics:

```bash
python3 evaluation.py
```

## Render

Render MIDI files into WAV audio files using FluidSynth with the `FluidR3_GM.sf2` SoundFont:

```bash
python3 render.py [OPTIONS]
```

### Arguments

- `--task A/B`  
  Select the generation task:
  - `A`: render MIDI files generated by Task A
  - `B`: render MIDI files generated by Task B
  - `O`: render MIDI files from the original dataset
  - `U`: render MIDI files generated by the bonus task

## Bonus

Run the scripts in the following order:

```bash
python3 bonus_tokenization.py
python3 bonus_train.py
python3 bonus_predict.py
python3 bonus_evaluation.py
```

## Plotting Results

To generate the line charts used in the report:

```bash
python3 draw.py
python3 bonus_draw.py
```
